# darkm.dev branding

Logo assets for the darkm.dev Logto sign-in experience (Console → Sign-in experience → Branding).

| File | Use |
|---|---|
| `darkmdev-logo-light.svg` | App logo on light backgrounds |
| `darkmdev-logo-dark.svg` | App logo on dark backgrounds (dark mode) |
| `darkmdev-mark.svg` | Favicon / square icon |

Served via jsDelivr: `https://cdn.jsdelivr.net/gh/d-arken/logto@master/branding/<file>`

Wordmark is Space Grotesk Bold (OFL) converted to paths, so no font is needed at runtime.
Regenerate: `python generate.py SpaceGrotesk[wght].ttf . 700`
